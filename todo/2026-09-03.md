# 2026-09-03

## Shared AI across Red Alert 2 and World War III

- Added a native game selector when both games are installed. Switching games
  keeps the wrapper-owned AI service alive and remembers the selection.
- Reused the assistant, model settings, AUTO and remappable voice controls in
  the RA2 integration. The HUD now always displays the configured Ask shortcut.
- Moved voice-button translations into the shared UI and kept game-selection
  buttons above the full-screen input-blocking menu background.
- Added the active mod and observed actor display names to the bridge so RA2
  GIs/Conscripts are not described using Red Alert 1 names.
- Standardized bridge cell coordinates on map-storage coordinates, including
  orders, rally points, spatial layers and observations on isometric maps.
- Preserved the World War III faction/capability catalogue without alteration.
  RA2 custom-faction ports, original campaigns and Yuri's Revenge are not part
  of this integration.
