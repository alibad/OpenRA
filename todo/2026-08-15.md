# 2026-08-15

## What We Built

- The in-game AUTO control now reflects the assistant state acknowledged by the active game bridge.
- macOS packaging helpers now work reliably when strict shell error checking is enabled.

## What We Fixed

- AUTO no longer appears off while the assistant is actively controlling the player's forces because of a startup timing race.
- Packaging no longer crashes when a variable-length argument list ends normally.
- Clean release builds no longer fail when calculating the fallback hash for an empty map payload.

## Key Decisions

- Treat the game bridge as the authoritative source for AUTO state instead of relying on a one-time web request during UI construction.
- Make shared packaging helpers safe for strict callers rather than adding placeholder arguments in individual release scripts.
- Keep overloaded hash calls explicitly typed so release builds remain compatible across supported compiler versions.

## Breaking Changes

- None.
